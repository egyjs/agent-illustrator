# M3: First End-to-End MCP Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A model in an MCP client can create a document, draw with ops, see a PNG render, and export valid SVG through the published `agent-illustrator` stdio server.

**Architecture:**
- **Engine.** The engine gains `render/raster.ts` (resvg PNG with overlay and region options) and `render/export.ts` (SVGO).
- **Server modules.** `packages/mcp-server` gains five modules:
  - `config.ts`: limits from env vars.
  - `logging.ts`: pino to stderr.
  - `sessions.ts`: an in-memory `SessionStore`.
  - `tools.ts`: pure tool handlers that return MCP results.
  - `server.ts`: registers the tools on `McpServer`.
- **CLI.** `cli.ts` serves stdio by default.
- **Tests.** Tool handlers are unit-tested directly. One end-to-end test spawns the server over stdio, and `pnpm smoke` runs the same round trip against `dist/`.

**Tech Stack:**
- `@modelcontextprotocol/server` ^2.3.1 (`McpServer`, `serveStdio`, `fromJsonSchema`), `@modelcontextprotocol/client` ^2.3.1 (tests, smoke)
- `@resvg/resvg-js` 2.6.2, `svgo` ^4.1.0, `pino` ^10.4.0, zod ^4.6.5

**Spec:**
- [`PROJECT_INIT.md`](../../../PROJECT_INIT.md): §2.4–2.7, FR-11, FR-12.3, NFR-1/2/5/6, §5 M3.
- [`specs/2026-10-07-agent-illustrator-v1-design.md`](../specs/2026-10-07-agent-illustrator-v1-design.md):
  - S1/F4 (loose `apply_ops` schema with `additionalProperties: true`)
  - S4 (one published package)
  - S7 (decided here)
  - A4 (fonts in `engine/assets/fonts`; the runtime passes font paths)
- [`eval/clients.md`](../../../eval/clients.md) observation: the `apply_ops` description must carry per-op fields until `guide` exists (M9).

## Decisions taken in this plan (flag to the owner)

- **S7 adopted: input caps plus measured durations, no preemption.**
  - Caps: ops per batch, nodes, segments per path, render pixels, scale, documents per server.
  - Each tool call's duration is logged. Synchronous engine work is never interrupted.
  - The README documents this limit.
- **The `apply_ops` description lists every op's fields.** It shows signatures generated from the registry, e.g. `rect(x, y, width, height, radius?, id?, parent?, style?)`. This addresses the client observation that loose schemas hide fields. M9 moves the detail into `guide` and shortens the description.
- **Seeds.** When `create_document` gets no `seed`, the server picks one with `crypto.randomInt` and returns it, so a run can be replayed.
- **The R4 spike is not deleted in M3** (spec A4 said it would be). Claude Desktop and Claude Code on the owner's machine still launch `spikes/src/mcp-probe-server.ts`, and deleting it would break those registrations. It is deleted at the end, once the owner re-registers the clients to the real server.
- **Real-client acceptance.** It is automated through the SDK `Client` over stdio (`test/server.e2e.test.ts`) and the dist smoke script. The manual Claude Desktop / Claude Code check is added to `eval/clients.md` for the owner and does not block M3.

## Global Constraints

- **Runtime and syntax**
  - `engines.node` is `">=22.18"`. ESM only. Relative imports carry the `.ts` extension, type-only imports use `import type`, and only erasable syntax is allowed.
  - The engine never mentions MCP or LLMs.
  - Only `geometry` imports paper. `render` may import `@resvg/resvg-js` and `svgo`.
- **stdio cleanliness.** In stdio mode, stdout carries only MCP JSON-RPC. Logs go to stderr (fd 2) through pino. No `console.log` anywhere in `mcp-server/src`.
- **MCP tool schemas** (spec S1)
  - No top-level `oneOf`/`anyOf`, and no `$ref`/`$defs`.
  - The `apply_ops` item schema is `{ type: 'object', properties: { op: { enum: [...] } }, required: ['op'], additionalProperties: true }`, through `fromJsonSchema` (F4).
  - Full per-op validation happens in the engine (`executeBatch`).
  - `render` declares no `outputSchema`; images are dropped when one is set (spec S1, Claude Code issue 31208).
- **Tool failures are results, not crashes.** Every failure returns `isError: true` with JSON `{ "error": { code, message, hint } }`. Unexpected exceptions become `internal_error`.
- **Third-party runtime deps** of engine code that reaches the bundle are listed in `packages/mcp-server/package.json` `dependencies` (S4). The bundle keeps them external.
- **Workflow**
  - Branch `m3-mcp`, created from `main` after M2 is merged.
  - Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - Shell: no `>` redirects, no `bash`, no `node -e`.

## Review Focus

1. **A stray byte on stdout corrupts the stream.** This covers logging, warnings and library output while serving. Test: Task 5 (`writes nothing but JSON-RPC lines to stdout`).
2. **Every failing call comes back as an `isError` result with code, message and hint.** That includes an unknown `doc_id`, malformed ops, a mid-batch failure, a size cap and an engine bug. None may crash the server or surface as a protocol error. Tests: Task 4 (`… returns isError …`) and Task 5 (`a failing batch …`).
3. **The advertised `apply_ops` schema.** It must carry the loose item, `additionalProperties: true`, the op enum from the registry, and no `$ref`/`oneOf`. Tests: Task 4 (`apply_ops input schema …`) and Task 5 (`lists four tools …`).
4. **Render size limits.** A huge scale or region must give `limit_exceeded`, never a giant allocation. A region partly outside the canvas renders the backdrop. Test: Task 1 (`refuses renders above the pixel cap …`).
5. **The published bundle must find its fonts and agent-kit content in `dist/` and serve.** Tests: Task 5 (`--doctor` checks fonts) and Task 6 (the smoke round trip against `dist/cli.mjs`).

```ts
import { Resvg } from '@resvg/resvg-js';
import { EngineError } from '../errors.ts';
import type { Box } from '../geometry/types.ts';
import type { Doc } from '../scene/model.ts';
import { worldBounds } from '../scene/query.ts';
import { toSvg } from './svg.ts';

export type Overlay = 'ids' | 'bounds' | 'grid';
export type RasterFonts = { readonly files: readonly string[]; readonly defaultFamily: string };
export type RasterOptions = {
  /** Output pixels per canvas unit; default 1. */
  readonly scale?: number;
  /** Canvas-space area to render; default the whole canvas. */
  readonly region?: Box;
  /** Drawn on top as a separate layer; never part of the document or its export. */
  readonly overlays?: readonly Overlay[];
  /** Grid spacing in canvas units; default a round step near a tenth of the shorter side. */
  readonly grid?: number;
  /** Font files for text and overlay labels. Without them, system fonts are used. */
  readonly fonts?: RasterFonts;
  /** Backdrop behind transparent areas; default white. */
  readonly background?: string;
  readonly maxPixels?: number;
};
export type Raster = { readonly width: number; readonly height: number; readonly png: Uint8Array; readonly pixels: Uint8Array };

export const MAX_RENDER_PIXELS = 4096 * 4096;
export const MAX_SCALE = 8;

/** SVG → PNG through resvg, with optional region crop, scale and overlays (FR-11.1). */
export function rasterize(doc: Doc, options: RasterOptions = {}): Raster {
  const scale = options.scale ?? 1;
  if (!(scale > 0 && scale <= MAX_SCALE)) {
    throw new EngineError('invalid_input', `scale must be in (0, ${MAX_SCALE}], got ${scale}`, 'Use 1 for actual size, 2 to zoom in, 0.5 for a thumbnail.');
  }
  const region = options.region ?? { x: 0, y: 0, width: doc.canvas.width, height: doc.canvas.height };
  if (!(region.width > 0 && region.height > 0)) {
    throw new EngineError('invalid_input', 'render region needs a positive width and height', 'Give region as { x, y, width, height } in canvas units.');
  }
  const width = Math.max(1, Math.round(region.width * scale));
  const height = Math.max(1, Math.round(region.height * scale));
  const maxPixels = options.maxPixels ?? MAX_RENDER_PIXELS;
  if (width * height > maxPixels) {
    throw new EngineError(
      'limit_exceeded',
      `a ${width}×${height} render exceeds the ${maxPixels}-pixel limit`,
      'Lower scale, or render a smaller region and zoom into the part you need.',
    );
  }
  const body = toSvg(doc);
  const inner = body.slice(body.indexOf('>') + 1, body.lastIndexOf('</svg>'));
  const overlay = overlaySvg(doc, region, scale, options.overlays ?? [], options.grid);
  const svg =
    `<svg xmlns="http://www.w3.org/2000/svg" width="${width}" height="${height}" ` +
    `viewBox="${region.x} ${region.y} ${region.width} ${region.height}">${inner}${overlay}</svg>`;
  const fonts = options.fonts;
  const image = new Resvg(svg, {
    background: options.background ?? 'white',
    font: fonts
      ? { fontFiles: [...fonts.files], loadSystemFonts: false, defaultFontFamily: fonts.defaultFamily }
      : { loadSystemFonts: true },
  }).render();
  return { width: image.width, height: image.height, png: image.asPng(), pixels: image.pixels };
}

/** A round step (1, 2 or 5 × 10^k) near a tenth of the shorter side. */
function niceStep(span: number): number {
  const raw = span / 10;
  const pow = 10 ** Math.floor(Math.log10(raw));
  return [1, 2, 5, 10].map((m) => m * pow).find((s) => s >= raw) ?? raw;
}

function overlaySvg(doc: Doc, region: Box, scale: number, overlays: readonly Overlay[], gridStep?: number): string {
  if (overlays.length === 0) return '';
  const px = 1 / scale; // one output pixel, in canvas units
  const f = (v: number) => String(Number(v.toFixed(3)));
  const parts: string[] = ['<g id="__overlay">'];
  if (overlays.includes('grid')) {
    const step = gridStep ?? niceStep(Math.min(doc.canvas.width, doc.canvas.height));
    const label = `font-size="${f(10 * px)}" fill="#00708f"`;
    for (let x = Math.ceil(region.x / step) * step; x <= region.x + region.width; x += step) {
      parts.push(`<path d="M${f(x)} ${f(region.y)} V${f(region.y + region.height)}" stroke="#00a6d6" stroke-opacity="0.45" stroke-width="${f(px)}"/>`);
      parts.push(`<text x="${f(x + 2 * px)}" y="${f(region.y + 10 * px)}" ${label}>${f(x)}</text>`);
    }
    for (let y = Math.ceil(region.y / step) * step; y <= region.y + region.height; y += step) {
      parts.push(`<path d="M${f(region.x)} ${f(y)} H${f(region.x + region.width)}" stroke="#00a6d6" stroke-opacity="0.45" stroke-width="${f(px)}"/>`);
      parts.push(`<text x="${f(region.x + 2 * px)}" y="${f(y - 2 * px)}" ${label}>${f(y)}</text>`);
    }
  }
  const ids = Object.keys(doc.nodes);
  if (overlays.includes('bounds')) {
    for (const id of ids) {
      const b = worldBounds(doc, id);
      if (!b) continue;
      const color = doc.nodes[id]!.type === 'group' ? '#7a00ff' : '#ff00aa';
      parts.push(
        `<rect x="${f(b.x)}" y="${f(b.y)}" width="${f(b.width)}" height="${f(b.height)}" fill="none" stroke="${color}" ` +
          `stroke-width="${f(px)}" stroke-dasharray="${f(4 * px)} ${f(3 * px)}"/>`,
      );
    }
  }
  if (overlays.includes('ids')) {
    for (const id of ids) {
      const b = worldBounds(doc, id);
      if (!b) continue;
      const size = 11 * px;
      parts.push(
        `<rect x="${f(b.x)}" y="${f(b.y)}" width="${f((id.length * 6.5 + 4) * px)}" height="${f(14 * px)}" fill="#ffffff" fill-opacity="0.85"/>`,
        `<text x="${f(b.x + 2 * px)}" y="${f(b.y + 11 * px)}" font-size="${f(size)}" fill="#c00070">${id}</text>`,
      );
    }
  }
  parts.push('</g>');
  return parts.join('');
}
```

```ts
import { optimize } from 'svgo';
import { EngineError } from '../errors.ts';
import type { Doc } from '../scene/model.ts';
import { toSvg } from './svg.ts';

export type ExportOptions = { readonly precision?: number; readonly optimize?: boolean; readonly stripIds?: boolean };

/**
 * Final SVG (FR-11.3): tokens resolved, coordinates rounded to `precision` decimals (default 2),
 * then SVGO with ids and groups preserved unless `stripIds` is set.
 */
export function exportSvg(doc: Doc, options: ExportOptions = {}): string {
  const precision = options.precision ?? 2;
  if (!Number.isInteger(precision) || precision < 0 || precision > 6) {
    throw new EngineError('invalid_input', `precision must be a whole number 0..6, got ${precision}`, 'Use 2 for most drawings, 0 for pixel art.');
  }
  const raw = toSvg(doc, { precision });
  if (options.optimize === false) return options.stripIds ? raw.replace(/ id="[^"]*"/g, '') : raw;
  const overrides: Record<string, false> = { collapseGroups: false };
  if (!options.stripIds) overrides.cleanupIds = false;
  return optimize(raw, { multipass: true, floatPrecision: precision, plugins: [{ name: 'preset-default', params: { overrides } }] }).data;
}
```

```ts
export type ServerConfig = {

/** Limits and paths from AGENT_ILLUSTRATOR_* variables; malformed values stop the server at startup (NFR-1). */
export function loadConfig(env: Record<string, string | undefined> = process.env): ServerConfig {
  const int = (name: string, fallback: number): number => {
    const raw = env[`AGENT_ILLUSTRATOR_${name}`];
    if (raw === undefined || raw === '') return fallback;
    const v = Number(raw);
    if (!Number.isSafeInteger(v) || v <= 0) throw new Error(`AGENT_ILLUSTRATOR_${name} must be a positive integer, got "${raw}"`);
    return v;

  return {
    limits: {
      maxOpsPerBatch: int('MAX_OPS', DEFAULT_LIMITS.maxOpsPerBatch),
      maxNodes: int('MAX_NODES', DEFAULT_LIMITS.maxNodes),
      maxSegmentsPerPath: int('MAX_SEGMENTS', DEFAULT_LIMITS.maxSegmentsPerPath),
    },
    maxDocuments: int('MAX_DOCUMENTS', 50),
    maxRenderPixels: int('MAX_RENDER_PIXELS', MAX_RENDER_PIXELS),
    renderDir: env.AGENT_ILLUSTRATOR_RENDER_DIR || join(tmpdir(), 'agent-illustrator'),
```

```ts
import { DocumentStore, EngineError, type Doc } from '@agent-illustrator/engine';

export type Session = {
  readonly id: string;
  readonly store: DocumentStore;
  /** What "$last" refers to in the next batch. */
  lastCreated: string | undefined;
};

/** Where documents live between tool calls (FR-12.3); a Redis store can implement this later. */
export interface SessionStore {
  create(doc: Doc): Session;
  get(id: string): Session;
  size(): number;
}

export class MemorySessionStore implements SessionStore {
  readonly #sessions = new Map<string, Session>();
  readonly #max: number;
  #next = 1;

  constructor(maxDocuments: number) {
    this.#max = maxDocuments;
  }

  create(doc: Doc): Session {
    if (this.#sessions.size >= this.#max) {
      throw new EngineError('limit_exceeded', `this server already holds ${this.#max} documents`, 'Keep working in an existing doc_id instead of creating new ones.');
    }
    const session: Session = { id: `doc-${this.#next++}`, store: new DocumentStore(doc), lastCreated: undefined };
    this.#sessions.set(session.id, session);
    return session;
  }

  get(id: string): Session {
    const session = this.#sessions.get(id);
    if (!session) {
      const open = [...this.#sessions.keys()];
      throw new EngineError(
        'unknown_id',
        `no document "${id}"`,
        open.length > 0 ? `Open documents: ${open.join(', ')}.` : 'Call create_document first and use the doc_id it returns.',
      );
    }
    return session;
  }

  size(): number {
    return this.#sessions.size;
  }
}
```

```ts
export type ToolDeps = {
  readonly sessions: SessionStore;
  readonly registry: Registry;
  readonly config: ServerConfig;
  readonly fonts: RasterFonts;
  readonly log: Logger;
};
type Content = { type: 'text'; text: string } | { type: 'image'; data: string; mimeType: 'image/png' };
export type ToolResult = { content: Content[]; isError?: boolean };

const text = (value: unknown): Content => ({ type: 'text', text: typeof value === 'string' ? value : JSON.stringify(value) });

/** Runs a tool body; engine errors and surprises both come back as isError results the model can act on. */
function guarded(deps: ToolDeps, tool: string, body: () => ToolResult): ToolResult {
  try {
    return body();
  } catch (e) {
    const error =
      e instanceof EngineError
        ? e.info
        : { code: 'internal_error', message: e instanceof Error ? e.message : String(e), hint: 'This is a server bug, not a mistake in the call. Try a simpler request.' };
    if (!(e instanceof EngineError)) deps.log.error({ tool, err: e }, 'tool failed unexpectedly');
    return { isError: true, content: [text({ error })] };
  }
}

const round = (v: number) => Math.round(v * 100) / 100;
const roundBox = (b: Box) => ({ x: round(b.x), y: round(b.y), width: round(b.width), height: round(b.height) });

/** What the model sees for one op: no empty warnings, bounds rounded to 0.01. */
function compact(o: OpOutcome): Record<string, unknown> {
  if (o.status === 'error' || o.status === 'skipped') return { ...o };
  const { warnings, bounds, ...rest } = o;
  return { ...rest, ...(bounds ? { bounds: roundBox(bounds) } : {}), ...(warnings.length > 0 ? { warnings } : {}) };
}

  width: z.number().positive().max(16384).describe('Canvas width in px'),
  height: z.number().positive().max(16384).describe('Canvas height in px'),
  background: z.string().optional().describe('Canvas color, e.g. "#ffffff"; omit for transparent'),
  seed: z.number().int().optional().describe('Seed for generators; omit for a random one (returned)'),
});

export function createDocumentTool(deps: ToolDeps, input: z.output<typeof createDocumentInput>): ToolResult {
  return guarded(deps, 'create_document', () => {
    const seed = input.seed ?? randomInt(0, 2 ** 31);
    const doc = createDocument({ width: input.width, height: input.height, seed, ...(input.background === undefined ? {} : { background: input.background }) });
    const session = deps.sessions.create(doc);
    return { content: [text({ doc_id: session.id, width: doc.canvas.width, height: doc.canvas.height, seed })] };
  });
}

/** JSON Schema for apply_ops (spec S1, finding F4): loose items, per-op validation happens in the engine. */
export function applyOpsInputSchema(registry: Registry, limits: Limits): Record<string, unknown> {
  return {
    type: 'object',
    properties: {
      doc_id: { type: 'string', description: 'Document id from create_document' },
      ops: {
        type: 'array',
        minItems: 1,
        maxItems: limits.maxOpsPerBatch,
        description: 'Ops to apply in order; each is {"op": name, ...fields}',
        items: { type: 'object', properties: { op: { type: 'string', enum: registry.names() } }, required: ['op'], additionalProperties: true },
      },
      dry_run: { type: 'boolean', description: 'Validate and report without changing the document' },
    },
    required: ['doc_id', 'ops'],
    additionalProperties: false,
  };
}

/** One line per op, e.g. "rect(x, y, width, height, radius?, id?, parent?, style?)", from the registry schemas. */
export function opSignatures(registry: Registry): string {
  return registry
    .list()
    .map((def) => {
      const schema = z.toJSONSchema(def.schema, { io: 'input' }) as { properties?: Record<string, unknown>; required?: string[] };
      const required = new Set(schema.required ?? []);
      const fields = Object.keys(schema.properties ?? {});
      const ordered = [...fields.filter((f) => required.has(f)), ...fields.filter((f) => !required.has(f)).map((f) => `${f}?`)];
      return `${def.name}(${ordered.join(', ')})`;
    })
    .join('\n');
}

export type ApplyOpsInput = { doc_id: string; ops: unknown[]; dry_run?: boolean };

export function applyOpsTool(deps: ToolDeps, input: ApplyOpsInput): ToolResult {
  return guarded(deps, 'apply_ops', () => {
    const session = deps.sessions.get(input.doc_id);
    const result = executeBatch(deps.registry, session.store.doc, input.ops, {
      dryRun: input.dry_run ?? false,
      lastCreated: session.lastCreated,
      limits: deps.config.limits,
    });
    if (result.committed) {
      session.store.commit(result.doc);
      session.lastCreated = result.lastCreated;
    }
    const body = { ok: result.ok, committed: result.committed, doc_id: session.id, results: result.results.map(compact) };
    return result.ok ? { content: [text(body)] } : { isError: true, content: [text(body)] };
  });
}

const BoxInput = z.object({ x: z.number(), y: z.number(), width: z.number().positive(), height: z.number().positive() });

export const renderInput = z.object({
  doc_id: z.string(),
  overlays: z.array(z.enum(['ids', 'bounds', 'grid'])).optional().describe('Debug layers drawn on top: node ids, exact bounds, a coordinate grid'),
  region: BoxInput.optional().describe('Canvas-space area to render, in px; default the whole canvas'),
  scale: z.number().positive().max(8).optional().describe('Output pixels per canvas px; default 1'),
  grid: z.number().positive().optional().describe('Grid spacing in canvas px'),
});

export function renderTool(deps: ToolDeps, input: z.output<typeof renderInput>): ToolResult {
  return guarded(deps, 'render', () => {
    const session = deps.sessions.get(input.doc_id);
    const raster = rasterize(session.store.doc, {
      ...(input.scale === undefined ? {} : { scale: input.scale }),
      ...(input.region === undefined ? {} : { region: input.region }),
      ...(input.grid === undefined ? {} : { grid: input.grid }),
      overlays: input.overlays ?? [],
      fonts: deps.fonts,
      maxPixels: deps.config.maxRenderPixels,
    });
    let file: string | undefined;
    try {
      mkdirSync(deps.config.renderDir, { recursive: true });
      file = join(deps.config.renderDir, `${session.id}.png`);
      writeFileSync(file, raster.png);
    } catch (e) {
      deps.log.warn({ err: e }, 'could not write the render fallback file');
      file = undefined;
    }
    const summary = { doc_id: session.id, width: raster.width, height: raster.height, overlays: input.overlays ?? [], ...(file ? { file } : {}) };
    return { content: [text(summary), { type: 'image', data: Buffer.from(raster.png).toString('base64'), mimeType: 'image/png' }] };
  });
}

export const exportSvgInput = z.object({
  doc_id: z.string(),
  precision: z.number().int().min(0).max(6).optional().describe('Decimals for coordinates; default 2'),
  optimize: z.boolean().optional().describe('Run SVGO; default true'),
  strip_ids: z.boolean().optional().describe('Remove id attributes; default false'),
});

export function exportSvgTool(deps: ToolDeps, input: z.output<typeof exportSvgInput>): ToolResult {
  return guarded(deps, 'export_svg', () => {
    const session = deps.sessions.get(input.doc_id);
    const svg = exportSvg(session.store.doc, {
      ...(input.precision === undefined ? {} : { precision: input.precision }),
      ...(input.optimize === undefined ? {} : { optimize: input.optimize }),
      ...(input.strip_ids === undefined ? {} : { stripIds: input.strip_ids }),
    });
    return { content: [text(svg)] };
  });
}
```

```ts
/** Times a tool call and logs one JSON line per call (NFR-5). */
function logged(deps: ToolDeps, tool: string, docId: string | undefined, run: () => ToolResult): ToolResult {
  const start = performance.now();
  const result = run();
  deps.log.info({ tool, doc_id: docId, ms: Math.round(performance.now() - start), outcome: result.isError ? 'error' : 'ok' }, 'tool call');
  return result;
}

export function createServer(deps: ToolDeps, instructions: string): McpServer {
  const server = new McpServer({ name: 'agent-illustrator', version: pkg.version }, { instructions });

  server.registerTool(
    'create_document',
    {
      title: 'Create document',
      description: 'Create a new drawing canvas. Returns doc_id, which every other tool needs, and the seed used for generators.',
      inputSchema: createDocumentInput,
    },
    async (input) => logged(deps, 'create_document', undefined, () => createDocumentTool(deps, input)),
  );

  server.registerTool(
    'apply_ops',
    {
      title: 'Apply ops',
      description:
        'Apply a batch of drawing ops to a document, all or nothing. Each op is {"op": name, ...fields}. Numbers are canvas px; strings ' +
        'like "50%" are relative to the canvas. Give nodes short semantic ids; "$last" is the most recent node. Returns each op\'s ' +
        'status, id and exact bounds, or errors with a hint.\nOps:\n' +
        opSignatures(deps.registry) +
        '\nstyle fields: fill, stroke (CSS colors or "none"), strokeWidth, strokeCap, strokeJoin, strokeDash, miterLimit, opacity, fillOpacity, strokeOpacity.',
      inputSchema: fromJsonSchema<ApplyOpsInput>(applyOpsInputSchema(deps.registry, deps.config.limits)),
    },
    async (input) => logged(deps, 'apply_ops', input.doc_id, () => applyOpsTool(deps, input)),
  );

  server.registerTool(
    'render',
    {
      title: 'Render',
      description: 'Render the document to a PNG you can look at. Overlays: "ids" labels nodes, "bounds" outlines their exact bounds, "grid" draws coordinates. Use region and scale to zoom in.',
      inputSchema: renderInput,
      annotations: { readOnlyHint: true },
    },
    async (input) => logged(deps, 'render', input.doc_id, () => renderTool(deps, input)),
  );

  server.registerTool(
    'export_svg',
    {
      title: 'Export SVG',
      description: 'Return the finished SVG: colors resolved, coordinates rounded to precision, optimized with SVGO, ids kept unless strip_ids is true.',
      inputSchema: exportSvgInput,
      annotations: { readOnlyHint: true },
    },
    async (input) => logged(deps, 'export_svg', input.doc_id, () => exportSvgTool(deps, input)),
  );

  return server;
}
```

```ts
/** Sends a raw initialize request and resolves with every complete stdout line up to the response. */
function rawInitialize(): Promise<string[]> {
  return new Promise((resolve, reject) => {
    const child = spawn(process.execPath, [cli], { stdio: ['pipe', 'pipe', 'pipe'], env });
    let buf = '';
    const timer = setTimeout(() => {
      child.kill();
      reject(new Error(`no initialize response; stdout so far: ${buf}`));
    }, 15_000);
    child.stdout.setEncoding('utf8');
    child.stdout.on('data', (chunk: string) => {
      buf += chunk;
      const complete = buf.split('\n').slice(0, -1).filter((l) => l.trim() !== '');
      if (complete.some((l) => l.includes('"id":1'))) {
        clearTimeout(timer);
        child.kill();
        resolve(complete);
      }
    });
    const init = { jsonrpc: '2.0', id: 1, method: 'initialize', params: { protocolVersion: '2025-11-25', capabilities: {}, clientInfo: { name: 'raw', version: '0' } } };
    child.stdin.write(`${JSON.stringify(init)}\n`);
  });
}
```

````markdown
# agent-illustrator

Vector illustration tools for AI agents, served over MCP (stdio). The agent describes what to draw with
high-level ops; the engine owns the geometry, renders PNG previews the agent can look at, and exports clean SVG.

## Install

Requires Node.js 22.18 or newer. No native build step (resvg ships prebuilt binaries).

```sh
npx -y agent-illustrator --doctor   # checks the bundled fonts and content
```

## Client setup

Claude Code:

```sh
claude mcp add agent-illustrator -- npx -y agent-illustrator
```

Claude Desktop, Cursor, VS Code and other clients that read an `mcpServers` JSON block:

```json
{ "mcpServers": { "agent-illustrator": { "command": "npx", "args": ["-y", "agent-illustrator"] } } }
```

## Tools

| Tool | What it does |
|---|---|
| `create_document(width, height, background?, seed?)` | New canvas; returns `doc_id` and the seed |
| `apply_ops(doc_id, ops[], dry_run?)` | All-or-nothing batch of drawing ops; per-op status, id, exact bounds, errors with hints |
| `render(doc_id, overlays?, region?, scale?, grid?)` | PNG image (also written to disk), with optional id, bounds and grid overlays |
| `export_svg(doc_id, precision?, optimize?, strip_ids?)` | Final SVG, optimized with SVGO |

Ops so far: `rect`, `ellipse`, `polygon`, `line`, `style`, `group`, `delete`. The `apply_ops` description lists each op's fields.

## Limits

Set with environment variables. Exceeding a limit returns an error that says which one; nothing hangs.

| Variable | Default |
````
