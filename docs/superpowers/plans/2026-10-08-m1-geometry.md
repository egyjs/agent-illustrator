# M1: Geometry Module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `packages/engine/src/geometry`: the pure cubic-Bézier kernel. It covers evaluation, exact bounds and arc length; affine transforms; flattening, winding and area; path conversions and corner rounding; paper.js smoothing and fitting; and the four booleans. Every piece is covered by known-answer tests, and the booleans also get a regression suite.

**Architecture:**
- **Plain data.** Geometry is plain readonly data shaped like spec A3 (`Subpath = { start, segs: Seg[], closed }`, `Seg = [c1x,c1y,c2x,c2y,x,y]`).
- **Pure math in five files.** `bezier.ts`, `transform.ts`, `flatten.ts` and most of `paths.ts` are hand-written pure math (spec S3: no bezier-js).
- **paper.js behind one adapter.** paper.js is reached only through `paper-adapter.ts`:
  - The engine keeps one long-lived headless scope, activated on every call, and never inserts items (finding F5).
  - `paths.ts` uses the adapter for `smooth` and `fit`, and `boolean.ts` uses it for booleans (D5).
  - Every boolean result is reoriented before conversion (finding F3).
- **Nothing exported yet.** Nothing outside `geometry` imports it in M1. Scene (M2) is the first consumer.

**Tech Stack:**
- TypeScript ~6.0.3 (type stripping on Node ≥ 22.18)
- vitest ^5.0.3
- paper 0.12.18, core build `paper/dist/paper-core.js`

## Global Constraints

- **Runtime and syntax**
  - `engines.node` is `">=22.18"`. TypeScript is `~6.0.3`. All packages are ESM.
  - Relative imports carry the `.ts` extension. Type-only imports use `import type`.
  - Erasable syntax only: no enums, namespaces or parameter properties.
- **paper.js boundary**
  - Only `packages/engine/src/geometry/**` may import `paper`, and only as `paper/dist/paper-core.js`. Never `paper-jsdom` (§4.2, S6).
  - Test files are engine files too, so they may not import paper either. Tests reach paper only through `paper-adapter.ts`.
  - `geometry` imports nothing from `scene`, `ops`, `analysis`, `render` or `random` (ESLint `LAYER_BANS`).
- **Determinism.** `Math.random` is banned in `packages/engine/**`, tests included (D13). Fixtures are literal or deterministic, e.g. `Math.sin(i * 12.9898)`.
- **paper.js scope rules**
  - F5, which amends §2.4/§4.2 "fresh PaperScope per operation": one long-lived scope, `scope.activate()` at the start of every adapter call, and `insert: false` at every construction site, with `settings.insertItems = false` as a backstop.
  - F3: every boolean result gets `reorient(true, true)` before it is converted to plain data.
- **Data shapes**
  - D4: internal geometry is cubic Béziers only. Quadratics and arcs are converted on the way in.
  - Coordinates are SVG user space, with y pointing down. Positive signed area means clockwise on screen.
  - Rotation angles are in degrees; positive means clockwise on screen, as in SVG `rotate()`.
  - Canonical subpath form, produced by every geometry function:
    - A closed subpath's last segment ends exactly at `start`.
    - A straight segment stores its control points on its end points (paper's zero-handle form).
  - Consumers also accept a closed subpath without the explicit closing segment (implicit straight close).
- **Scope of M1**
  - Do not export geometry from `packages/engine/src/index.ts` in M1. There is no consumer yet, and the published `agent-illustrator` bundle stays unchanged.
  - Spec A4: the R1 spike test is deleted once the engine has its own paper tests (Task 7).
- **Workflow**
  - Work on branch `m1-geometry`, created from `main`. Commit messages are conventional and end with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - Commands run from the repo root in Git Bash.

## Review Focus

1. **Straight segments have a zero derivative at both ends.** Their control points sit on their end points, so the derivative vanishes at t = 0 and t = 1. Tangents, normals, corner detection and arc-length inversion must still return the chord direction, never NaN.
   - Tests: Task 1 (`tangentAt falls back to the chord…`, `walks a square by arc length…`) and Task 5 (`fillets a square…`).
2. **Implicitly closed and open subpaths used as fills.** This covers a closed subpath without an explicit closing segment, and an open subpath used as a fill. Bounds, area, winding and paper conversion must all follow SVG fill semantics.
   - Tests: Task 1 (`cubics adds a straight closing cubic…`), Task 4 (`an open subpath is closed for fill…`), Task 6 (`makes the closing segment explicit…`) and Task 7 (`treats an open operand as closed…`).
3. **evenodd shapes handed to booleans.** The hole must survive. paper reads the item's `fillRule`, so the adapter must set it.
   - Test: Task 7 (`honours evenodd holes in an operand`).
4. **Near-coincident and near-tangent operands.** Identical, near-tangent or barely overlapping operands must never throw and never return a zero-area loop. paper returns such a sliver for a 1e-6 overlap.
   - Tests: Task 7 (`identical operands…`, `near-tangent circles…`, `partially shared edge…`).
5. **paper state leaking across calls.** Many calls in a row, a callback that throws, and another scope activated in between must not grow the scope registry, leave items in the project, or attach items to the wrong scope.
   - Tests: Task 6 (the three `scope lifecycle` tests).

```ts
import { expect } from 'vitest';
import { pointAt } from '../../src/geometry/bezier.ts';
import type { Cubic, Subpath, Vec2 } from '../../src/geometry/types.ts';

/** 4/3·(√2 − 1) = 4/3·tan(π/8): quarter-circle handle length per unit radius. */
export const KAPPA = 0.5522847498307936;
/**
 * Exact area of a circle made of four KAPPA quarter arcs, per unit r². Green's theorem on one
 * quarter gives 0.5 + 0.6k − 0.15k²; four quarters give 2 + 2.4k − 0.6k² ≈ 3.1424723 (π + 2.8e-4).
 */
export const KAPPA_CIRCLE_AREA = 2 + 2.4 * KAPPA - 0.6 * KAPPA * KAPPA;

export function expectVec(actual: Vec2, expected: Vec2, digits = 9): void {
  expect(actual[0]).toBeCloseTo(expected[0], digits);
  expect(actual[1]).toBeCloseTo(expected[1], digits);
}

/** Axis-aligned square, clockwise on screen, straight segments with controls on the end points. */
export function square(x: number, y: number, s: number): Subpath {
  return {
    start: [x, y],
    closed: true,
    segs: [
      [x, y, x + s, y, x + s, y],
      [x + s, y, x + s, y + s, x + s, y + s],
      [x + s, y + s, x, y + s, x, y + s],
      [x, y + s, x, y, x, y],
    ],
  };
}

/** Circle from four KAPPA quarter arcs, clockwise on screen, starting at (cx + r, cy). */
export function kappaCircle(cx: number, cy: number, r: number): Subpath {
  const k = r * KAPPA;
  return {
    start: [cx + r, cy],
    closed: true,
    segs: [
      [cx + r, cy + k, cx + k, cy + r, cx, cy + r],
      [cx - k, cy + r, cx - r, cy + k, cx - r, cy],
      [cx - r, cy - k, cx - k, cy - r, cx, cy - r],
      [cx + k, cy - r, cx + r, cy - k, cx + r, cy],
    ],
  };
}

/** Reference arc length: a fine uniform-t polyline. */
export function polylineLength(c: Cubic, steps: number): number {
  let total = 0;
  let [px, py] = pointAt(c, 0);
  for (let i = 1; i <= steps; i++) {
    const [x, y] = pointAt(c, i / steps);
    total += Math.hypot(x - px, y - py);
    px = x;
    py = y;
  }
  return total;
}
```

```ts
/**
 * Plain geometry data shared by the engine (spec A3). SVG user space: x right, y down.
 * Positive signed area means clockwise on screen.
 */
export type Vec2 = readonly [x: number, y: number];

/** One cubic segment from the previous end point: [c1x, c1y, c2x, c2y, x, y]. */
export type Seg = readonly [c1x: number, c1y: number, c2x: number, c2y: number, x: number, y: number];

/**
 * A run of cubic segments. Closed subpaths built by geometry end their last segment exactly at
 * `start`; consumers also accept a closed subpath without that segment (implicit straight close).
 */
export type Subpath = { readonly start: Vec2; readonly segs: readonly Seg[]; readonly closed: boolean };

/** One cubic as its four points P0..P3. */
export type Cubic = readonly [x0: number, y0: number, x1: number, y1: number, x2: number, y2: number, x3: number, y3: number];

/** Affine matrix in SVG order: x' = a·x + c·y + e, y' = b·x + d·y + f. */
export type Mat6 = readonly [a: number, b: number, c: number, d: number, e: number, f: number];

export type Box = { readonly x: number; readonly y: number; readonly width: number; readonly height: number };

export type FillRule = 'nonzero' | 'evenodd';
```

`packages/engine/src/geometry/bezier.ts`:

```ts
import type { Box, Cubic, Subpath, Vec2 } from './types.ts';

const TINY = 1e-12;

/** Straight cubic with control points on its end points. */
function lineCubic(x0: number, y0: number, x1: number, y1: number): Cubic {
  return [x0, y0, x0, y0, x1, y1, x1, y1];
}

/**
 * The subpath's cubics in drawing order. A closed subpath whose last segment does not end at
 * `start` gets a straight closing cubic. `closeForFill` does the same for open subpaths, because
 * SVG fills an open subpath as if it were closed.
 */
export function cubics(sp: Subpath, closeForFill = false): Cubic[] {
  const out: Cubic[] = [];
  let [x, y] = sp.start;
  for (const [c1x, c1y, c2x, c2y, ex, ey] of sp.segs) {
    out.push([x, y, c1x, c1y, c2x, c2y, ex, ey]);
    x = ex;
    y = ey;
  }
  if ((sp.closed || closeForFill) && (x !== sp.start[0] || y !== sp.start[1])) {
    out.push(lineCubic(x, y, sp.start[0], sp.start[1]));
  }
  return out;
}

/** B(t) = (1−t)³P0 + 3(1−t)²t·P1 + 3(1−t)t²·P2 + t³P3. */
export function pointAt(c: Cubic, t: number): Vec2 {
  const [x0, y0, x1, y1, x2, y2, x3, y3] = c;
  const mt = 1 - t;
  const w0 = mt * mt * mt, w1 = 3 * mt * mt * t, w2 = 3 * mt * t * t, w3 = t * t * t;
  return [w0 * x0 + w1 * x1 + w2 * x2 + w3 * x3, w0 * y0 + w1 * y1 + w2 * y2 + w3 * y3];
}

/** B'(t) = 3[(1−t)²(P1−P0) + 2(1−t)t(P2−P1) + t²(P3−P2)]. */
export function derivativeAt(c: Cubic, t: number): Vec2 {
  const [x0, y0, x1, y1, x2, y2, x3, y3] = c;
  const mt = 1 - t;
  const w0 = 3 * mt * mt, w1 = 6 * mt * t, w2 = 3 * t * t;
  return [w0 * (x1 - x0) + w1 * (x2 - x1) + w2 * (x3 - x2), w0 * (y1 - y0) + w1 * (y2 - y1) + w2 * (y3 - y2)];
}

/**
 * Unit tangent. Where the derivative vanishes (a control point on its end point, as in every
 * straight segment) the direction comes from the next distinct control point. A curve collapsed
 * to a point returns [1, 0].
 */
export function tangentAt(c: Cubic, t: number): Vec2 {
  const [dx, dy] = derivativeAt(c, t);
  const len = Math.hypot(dx, dy);
  if (len > TINY) return [dx / len, dy / len];
  const [x0, y0, x1, y1, x2, y2, x3, y3] = c;
  const candidates: Vec2[] =
    t <= 0.5
      ? [[x1 - x0, y1 - y0], [x2 - x0, y2 - y0], [x3 - x0, y3 - y0]]
      : [[x3 - x2, y3 - y2], [x3 - x1, y3 - y1], [x3 - x0, y3 - y0]];
  for (const [vx, vy] of candidates) {
    const l = Math.hypot(vx, vy);
    if (l > TINY) return [vx / l, vy / l];
  }
  return [1, 0];
}

/** Unit normal N = (−B'y, B'x)/|B'| (Appendix A). */
export function normalAt(c: Cubic, t: number): Vec2 {
  const [tx, ty] = tangentAt(c, t);
  return [-ty, tx];
}

/** True when both control points lie on the chord P0→P3 (within 1e-9 of its length), not past its ends. */
export function isStraight(c: Cubic): boolean {
  const [x0, y0, x1, y1, x2, y2, x3, y3] = c;
  const dx = x3 - x0, dy = y3 - y0;
  const len2 = dx * dx + dy * dy;
  if (len2 <= TINY * TINY) return Math.hypot(x1 - x0, y1 - y0) <= TINY && Math.hypot(x2 - x0, y2 - y0) <= TINY;
  const tol = 1e-9 * len2; // cross and dot products scale with len²
  const controls: Vec2[] = [[x1 - x0, y1 - y0], [x2 - x0, y2 - y0]];
  for (const [px, py] of controls) {
    const cross = dx * py - dy * px;
    const dot = dx * px + dy * py;
    if (Math.abs(cross) > tol || dot < -tol || dot > len2 + tol) return false;
  }
  return true;
}

/** Real roots of a·t² + b·t + c = 0, numerically stable; linear when a ≈ 0. */
function quadRoots(a: number, b: number, c: number): number[] {
  if (Math.abs(a) < TINY) return Math.abs(b) < TINY ? [] : [-c / b];
  const disc = b * b - 4 * a * c;
  if (disc < 0) return [];
  const q = -0.5 * (b + Math.sign(b || 1) * Math.sqrt(disc));
  return q === 0 ? [0] : [q / a, c / q];
}

/** Parameters in (0, 1) where one coordinate has a zero derivative (Appendix A "Exact bounds"). */
function extremaT(p0: number, p1: number, p2: number, p3: number): number[] {
  const a = 3 * (-p0 + 3 * p1 - 3 * p2 + p3);
  const b = 6 * (p0 - 2 * p1 + p2);
  const c = 3 * (p1 - p0);
  return quadRoots(a, b, c).filter((t) => t > 0 && t < 1);
}

/** Exact bounds of one cubic: end points plus derivative roots, never the control-point box. */
export function cubicBounds(c: Cubic): Box {
  const [x0, y0, x1, y1, x2, y2, x3, y3] = c;
  const xs = [x0, x3], ys = [y0, y3];
  for (const t of extremaT(x0, x1, x2, x3)) xs.push(pointAt(c, t)[0]);
  for (const t of extremaT(y0, y1, y2, y3)) ys.push(pointAt(c, t)[1]);
  const minX = Math.min(...xs), minY = Math.min(...ys);
  return { x: minX, y: minY, width: Math.max(...xs) - minX, height: Math.max(...ys) - minY };
}

/** Smallest box containing every box; null for none. */
export function unionBoxes(boxes: readonly Box[]): Box | null {
  if (boxes.length === 0) return null;
  let minX = Infinity, minY = Infinity, maxX = -Infinity, maxY = -Infinity;
  for (const b of boxes) {
    minX = Math.min(minX, b.x);
    minY = Math.min(minY, b.y);
    maxX = Math.max(maxX, b.x + b.width);
    maxY = Math.max(maxY, b.y + b.height);
  }
  return { x: minX, y: minY, width: maxX - minX, height: maxY - minY };
}

/** Exact bounds of the drawn geometry; subpaths without segments draw nothing and are ignored. */
export function pathBounds(subpaths: readonly Subpath[]): Box | null {
  return unionBoxes(subpaths.flatMap((sp) => cubics(sp).map(cubicBounds)));
}

// 5-point Gauss–Legendre nodes and weights on [−1, 1] (Appendix A "Arc length").
const GAUSS: readonly (readonly [x: number, w: number])[] = [
  [0, 0.5688888888888889],
  [-0.5384693101056831, 0.47862867049936647],
  [0.5384693101056831, 0.47862867049936647],
  [-0.906179845938664, 0.23692688505618908],
  [0.906179845938664, 0.23692688505618908],
];
const LENGTH_PIECES = 8;

function speed(c: Cubic, t: number): number {
  const [dx, dy] = derivativeAt(c, t);
  return Math.hypot(dx, dy);
}

/** ∫ |B'(t)| dt over [t0, t1] with one 5-point Gauss–Legendre rule. */
function gauss(c: Cubic, t0: number, t1: number): number {
  const half = (t1 - t0) / 2, mid = (t0 + t1) / 2;
  let sum = 0;
  for (const [x, w] of GAUSS) sum += w * speed(c, mid + half * x);
  return sum * half;
}

/** Arc length from 0 to t: Gauss–Legendre on 8 equal sub-intervals. */
export function cubicLength(c: Cubic, t = 1): number {
  let sum = 0;
  for (let i = 0; i < LENGTH_PIECES; i++) sum += gauss(c, (t * i) / LENGTH_PIECES, (t * (i + 1)) / LENGTH_PIECES);
  return sum;
}

/** Cumulative arc length s at evenly spaced t; both arrays hold samples + 1 entries, s[0] = 0. */
export type LengthTable = { readonly t: Float64Array; readonly s: Float64Array };

export function lengthTable(c: Cubic, samples = 32): LengthTable {
  const t = new Float64Array(samples + 1), s = new Float64Array(samples + 1);
  let prevT = 0, acc = 0;
  for (let i = 1; i <= samples; i++) {
    const ti = i / samples;
    acc += gauss(c, prevT, ti);
    t[i] = ti;
    s[i] = acc;
    prevT = ti;
  }
  return { t, s };
}

/**
 * Parameter t where the arc length from 0 reaches s (s is clamped to [0, total]): binary search in
 * the table, linear interpolation, then one Newton step on |B'(t)|.
 */
export function tAtLength(c: Cubic, table: LengthTable, s: number): number {
  const acc = table.s, ts = table.t;
  const n = acc.length - 1;
  const total = acc[n]!;
  if (s <= 0 || total <= 0) return 0;
  if (s >= total) return 1;
  let lo = 0, hi = n;
  while (hi - lo > 1) {
    const mid = (lo + hi) >> 1;
    if (acc[mid]! <= s) lo = mid;
    else hi = mid;
  }
  const s0 = acc[lo]!, s1 = acc[hi]!, t0 = ts[lo]!, t1 = ts[hi]!;
  let u = s1 > s0 ? t0 + ((s - s0) / (s1 - s0)) * (t1 - t0) : t0;
  const v = speed(c, u);
  if (v > TINY) u -= (s0 + gauss(c, t0, u) - s) / v;
  return Math.min(t1, Math.max(t0, u));
}

export type PathSample = { readonly point: Vec2; readonly tangent: Vec2 };
export type SubpathMeasure = { readonly length: number; at(s: number): PathSample };

/** Arc-length parameterization of the drawn subpath (no fill close); `at` clamps s to [0, length]. */
export function measure(sp: Subpath): SubpathMeasure {
  const parts = cubics(sp).map((c) => {
    const table = lengthTable(c);
    return { c, table, length: table.s[table.s.length - 1]! };
  });
  const length = parts.reduce((sum, p) => sum + p.length, 0);
  return {
    length,
    at(s: number): PathSample {
      let rest = Math.min(Math.max(s, 0), length);
      for (const [i, p] of parts.entries()) {
        if (rest <= p.length || i === parts.length - 1) {
          const t = tAtLength(p.c, p.table, rest);
          return { point: pointAt(p.c, t), tangent: tangentAt(p.c, t) };
        }
        rest -= p.length;
      }
      return { point: sp.start, tangent: [1, 0] };
    },
  };
}
```

```ts
import type { Mat6, Seg, Subpath, Vec2 } from './types.ts';

export const IDENTITY: Mat6 = [1, 0, 0, 1, 0, 0];

const toDeg = (rad: number) => (rad * 180) / Math.PI;

/** cos and sin of an angle in degrees, exact at multiples of 90° so axis-aligned results stay clean. */
export function cosSinDeg(deg: number): Vec2 {
  const q = ((deg % 360) + 360) % 360;
  if (q === 0) return [1, 0];
  if (q === 90) return [0, 1];
  if (q === 180) return [-1, 0];
  if (q === 270) return [0, -1];
  const r = (deg * Math.PI) / 180;
  return [Math.cos(r), Math.sin(r)];
}

/** Matrix product m × n: applies n first, then m (SVG transform-list order). */
export function multiply(m: Mat6, n: Mat6): Mat6 {
  const [a, b, c, d, e, f] = m;
  const [a2, b2, c2, d2, e2, f2] = n;
  return [a * a2 + c * b2, b * a2 + d * b2, a * c2 + c * d2, b * c2 + d * d2, a * e2 + c * f2 + e, b * e2 + d * f2 + f];
}

/** compose(m1, m2, …) = m1 × m2 × …, the same as transform="m1 m2 …" in SVG. */
export function compose(...ms: readonly Mat6[]): Mat6 {
  return ms.reduce(multiply, IDENTITY);
}

export function translate(tx: number, ty = 0): Mat6 {
  return [1, 0, 0, 1, tx, ty];
}

export function scale(sx: number, sy = sx): Mat6 {
  return [sx, 0, 0, sy, 0, 0];
}

/** SVG rotate(deg, cx, cy): positive angles turn clockwise on screen, about the pivot (cx, cy). */
export function rotate(deg: number, cx = 0, cy = 0): Mat6 {
  const [cos, sin] = cosSinDeg(deg);
  const r: Mat6 = [cos, sin, -sin, cos, 0, 0];
  return cx === 0 && cy === 0 ? r : compose(translate(cx, cy), r, translate(-cx, -cy));
}

export function skewX(deg: number): Mat6 {
  return [1, 0, Math.tan((deg * Math.PI) / 180), 1, 0, 0];
}

export function skewY(deg: number): Mat6 {
  return [1, Math.tan((deg * Math.PI) / 180), 0, 1, 0, 0];
}

/** Inverse matrix, or null when m is singular (det ≈ 0 relative to its own terms). */
export function invert(m: Mat6): Mat6 | null {
  const [a, b, c, d, e, f] = m;
  const det = a * d - b * c;
  if (Math.abs(det) <= 1e-12 * (Math.abs(a * d) + Math.abs(b * c))) return null;
  return [d / det, -b / det, -c / det, a / det, (c * f - d * e) / det, (b * e - a * f) / det];
}

export function applyToPoint(m: Mat6, p: Vec2): Vec2 {
  const [a, b, c, d, e, f] = m;
  return [a * p[0] + c * p[1] + e, b * p[0] + d * p[1] + f];
}

/** Béziers are affine-invariant: transforming the control points transforms the curve exactly. */
export function applyToSubpaths(m: Mat6, subpaths: readonly Subpath[]): Subpath[] {
  const [a, b, c, d, e, f] = m;
  const x = (px: number, py: number) => a * px + c * py + e;
  const y = (px: number, py: number) => b * px + d * py + f;
  return subpaths.map((sp) => ({
    start: [x(sp.start[0], sp.start[1]), y(sp.start[0], sp.start[1])],
    closed: sp.closed,
    segs: sp.segs.map(
      ([c1x, c1y, c2x, c2y, ex, ey]): Seg => [x(c1x, c1y), y(c1x, c1y), x(c2x, c2y), y(c2x, c2y), x(ex, ey), y(ex, ey)],
    ),
  }));
}

/** m = translate · rotate · skewX · scale, in SVG order. A reflection shows up as a negative scale[1]. */
export type Decomposed = { readonly translate: Vec2; readonly rotate: number; readonly skewX: number; readonly scale: Vec2 };

/**
 * Columns (a, b) and (c, d) are the images of the x and y axes:
 * (a, b) = sx·(cos θ, sin θ) and (c, d) = sy·(k·cos θ − sin θ, k·sin θ + cos θ), with k = tan(skewX).
 * So sx = |(a, b)|, θ = atan2(b, a), sy = det / sx, and k = (a·c + b·d) / (sx·sy).
 */
export function decompose(m: Mat6): Decomposed {
  const [a, b, c, d, e, f] = m;
  const sx = Math.hypot(a, b);
  if (sx < 1e-12) {
    // The x axis collapsed: carry the whole linear part on the y axis.
    const sy = Math.hypot(c, d);
    return { translate: [e, f], rotate: sy < 1e-12 ? 0 : toDeg(Math.atan2(-c, d)), skewX: 0, scale: [0, sy] };
  }
  const sy = (a * d - b * c) / sx;
  const k = sy === 0 ? 0 : (a * c + b * d) / (sx * sy);
  return { translate: [e, f], rotate: toDeg(Math.atan2(b, a)), skewX: toDeg(Math.atan(k)), scale: [sx, sy] };
}

export function recompose(p: Decomposed): Mat6 {
  return compose(translate(p.translate[0], p.translate[1]), rotate(p.rotate), skewX(p.skewX), scale(p.scale[0], p.scale[1]));
}
```

```ts
import { cosSinDeg } from './transform.ts';
import type { Seg, Subpath, Vec2 } from './types.ts';

/** 4/3·(√2 − 1) = 4/3·tan(π/8): quarter-circle handle length per unit radius. */
const KAPPA = 0.5522847498307936;

/** Straight segment to `to`, control points on the end points (paper's zero-handle form). */
export function line(from: Vec2, to: Vec2): Seg {
  return [from[0], from[1], to[0], to[1], to[0], to[1]];
}

/** Exact degree elevation (Appendix A): C1 = P0 + ⅔(Q − P0), C2 = P2 + ⅔(Q − P2). */
export function quadToCubic(p0: Vec2, q: Vec2, p2: Vec2): Seg {
  return [
    p0[0] + (2 / 3) * (q[0] - p0[0]),
    p0[1] + (2 / 3) * (q[1] - p0[1]),
    p2[0] + (2 / 3) * (q[0] - p2[0]),
    p2[1] + (2 / 3) * (q[1] - p2[1]),
    p2[0],
    p2[1],
  ];
}

/** Drops consecutive duplicate points and, for closed input, a last point equal to the first. */
export function distinct(points: readonly Vec2[], closed: boolean): Vec2[] {
  const out: Vec2[] = [];
  for (const p of points) {
    const q = out.at(-1);
    if (!q || q[0] !== p[0] || q[1] !== p[1]) out.push(p);
  }
  const first = out[0], last = out.at(-1);
  if (closed && out.length > 1 && first && last && first[0] === last[0] && first[1] === last[1]) out.pop();
  return out;
}

/** Straight segments through the points; a closed polyline ends with an explicit closing segment. */
export function polyline(points: readonly Vec2[], closed: boolean): Subpath {
  const pts = distinct(points, closed);
  const first = pts[0];
  if (!first) throw new RangeError('polyline needs at least one point');
  const segs: Seg[] = [];
  for (let i = 1; i < pts.length; i++) segs.push(line(pts[i - 1]!, pts[i]!));
  if (closed && pts.length > 1) segs.push(line(pts.at(-1)!, first));
  return { start: first, segs, closed };
}

/** Ellipse from four quarter arcs, clockwise on screen, starting at (cx + rx, cy). */
export function ellipse(cx: number, cy: number, rx: number, ry: number): Subpath {
  const kx = rx * KAPPA, ky = ry * KAPPA;
  return {
    start: [cx + rx, cy],
    closed: true,
    segs: [
      [cx + rx, cy + ky, cx + kx, cy + ry, cx, cy + ry],
      [cx - kx, cy + ry, cx - rx, cy + ky, cx - rx, cy],
      [cx - rx, cy - ky, cx - kx, cy - ry, cx, cy - ry],
      [cx + kx, cy - ry, cx + rx, cy - ky, cx + rx, cy],
    ],
  };
}

/**
 * SVG elliptical arc (endpoint form, SVG 2 implementation notes) as cubics of at most 90° each,
 * with handle length 4/3·tan(δ/4). Radii too small to reach `to` are scaled up; a zero radius gives
 * a straight segment; equal end points give no segments. The last segment ends exactly at `to`.
 */
export function arcToCubics(
  from: Vec2,
  rx: number,
  ry: number,
  rotationDeg: number,
  largeArc: boolean,
  sweep: boolean,
  to: Vec2,
): Seg[] {
  const [x0, y0] = from, [x1, y1] = to;
  if (x0 === x1 && y0 === y1) return [];
  let ax = Math.abs(rx), ay = Math.abs(ry);
  if (ax === 0 || ay === 0) return [line(from, to)];
  const [cos, sin] = cosSinDeg(rotationDeg);
  const dx2 = (x0 - x1) / 2, dy2 = (y0 - y1) / 2;
  const x1p = cos * dx2 + sin * dy2, y1p = -sin * dx2 + cos * dy2;
  const lambda = (x1p * x1p) / (ax * ax) + (y1p * y1p) / (ay * ay);
  if (lambda > 1) {
    ax *= Math.sqrt(lambda);
    ay *= Math.sqrt(lambda);
  }
  const ax2 = ax * ax, ay2 = ay * ay;
  const num = ax2 * ay2 - ax2 * y1p * y1p - ay2 * x1p * x1p;
  const den = ax2 * y1p * y1p + ay2 * x1p * x1p;
  const coef = (largeArc !== sweep ? 1 : -1) * Math.sqrt(Math.max(0, num / den));
  const cxp = (coef * ax * y1p) / ay, cyp = (-coef * ay * x1p) / ax;
  const cx = cos * cxp - sin * cyp + (x0 + x1) / 2;
  const cy = sin * cxp + cos * cyp + (y0 + y1) / 2;
  const ux = (x1p - cxp) / ax, uy = (y1p - cyp) / ay;
  const vx = (-x1p - cxp) / ax, vy = (-y1p - cyp) / ay;
  let delta = Math.atan2(ux * vy - uy * vx, ux * vx + uy * vy);
  if (!sweep && delta > 0) delta -= 2 * Math.PI;
  else if (sweep && delta < 0) delta += 2 * Math.PI;
  return ellipticArc(cx, cy, ax, ay, cos, sin, Math.atan2(uy, ux), delta, to);
}

/** Center-form arc from angle theta1 through delta, split into pieces of at most 90°. */
function ellipticArc(
  cx: number,
  cy: number,
  rx: number,
  ry: number,
  cos: number,
  sin: number,
  theta1: number,
  delta: number,
  end: Vec2,
): Seg[] {
  const n = Math.max(1, Math.ceil(Math.abs(delta) / (Math.PI / 2) - 1e-9));
  const step = delta / n;
  const k = (4 / 3) * Math.tan(step / 4);
  // E(θ) maps the unit circle through scale(rx, ry), the rotation and translate(cx, cy); D(θ) = dE/dθ.
  const ex = (t: number) => cx + rx * Math.cos(t) * cos - ry * Math.sin(t) * sin;
  const ey = (t: number) => cy + rx * Math.cos(t) * sin + ry * Math.sin(t) * cos;
  const dx = (t: number) => -rx * Math.sin(t) * cos - ry * Math.cos(t) * sin;
  const dy = (t: number) => -rx * Math.sin(t) * sin + ry * Math.cos(t) * cos;
  const segs: Seg[] = [];
  for (let i = 0; i < n; i++) {
    const a = theta1 + i * step, b = a + step;
    const last = i === n - 1;
    const x3 = last ? end[0] : ex(b), y3 = last ? end[1] : ey(b);
    segs.push([ex(a) + k * dx(a), ey(a) + k * dy(a), x3 - k * dx(b), y3 - k * dy(b), x3, y3]);
  }
  return segs;
}
```

```ts
/** Distance from p to the closest point of a polyline. */
export function distanceToPolyline(p: Vec2, pts: readonly Vec2[]): number {
  let best = Infinity;
  for (let i = 0; i + 1 < pts.length; i++) {
    const [ax, ay] = pts[i]!, [bx, by] = pts[i + 1]!;
    const dx = bx - ax, dy = by - ay, len2 = dx * dx + dy * dy;
    const t = len2 > 0 ? Math.max(0, Math.min(1, ((p[0] - ax) * dx + (p[1] - ay) * dy) / len2)) : 0;
    best = Math.min(best, Math.hypot(p[0] - ax - t * dx, p[1] - ay - t * dy));
  }
  return best;
}
```

```ts
import { cubics, isStraight, pointAt } from './bezier.ts';
import type { Cubic, FillRule, Subpath, Vec2 } from './types.ts';

/** Upper bound on pieces per cubic. Past it the tolerance is not met; input size caps belong to ops. */
export const MAX_FLATTEN_STEPS = 1024;

/**
 * Polyline through one cubic within `tolerance`, both end points included. Wang's formula:
 * n = ⌈√(3M / (4·tol))⌉ with M = max(|P0 − 2P1 + P2|, |P1 − 2P2 + P3|). Straight cubics need one piece.
 */
export function flattenCubic(c: Cubic, tolerance: number): Vec2[] {
  if (!(tolerance > 0)) throw new RangeError(`tolerance must be > 0, got ${tolerance}`);
  const [x0, y0, x1, y1, x2, y2, x3, y3] = c;
  if (isStraight(c)) return [[x0, y0], [x3, y3]];
  const m = Math.max(Math.hypot(x0 - 2 * x1 + x2, y0 - 2 * y1 + y2), Math.hypot(x1 - 2 * x2 + x3, y1 - 2 * y2 + y3));
  const n = Math.min(MAX_FLATTEN_STEPS, Math.max(1, Math.ceil(Math.sqrt((3 * m) / (4 * tolerance)))));
  const pts: Vec2[] = [[x0, y0]];
  for (let i = 1; i < n; i++) pts.push(pointAt(c, i / n));
  pts.push([x3, y3]);
  return pts;
}

function polylineOf(sp: Subpath, tolerance: number, closeForFill: boolean): Vec2[] {
  const pts: Vec2[] = [sp.start];
  for (const c of cubics(sp, closeForFill)) pts.push(...flattenCubic(c, tolerance).slice(1));
  return pts;
}

/** Polyline through the drawn subpath; a closed subpath ends with a copy of its start point. */
export function flatten(sp: Subpath, tolerance = 0.25): Vec2[] {
  return polylineOf(sp, tolerance, false);
}

/** A closed polygon: its last point equals its first. */
export type Ring = readonly Vec2[];

/** One ring per drawn subpath, for fill tests. Open subpaths are closed, as SVG fills them. */
export function rings(subpaths: readonly Subpath[], tolerance = 0.25): Ring[] {
  return subpaths.filter((sp) => sp.segs.length > 0).map((sp) => polylineOf(sp, tolerance, true));
}

/**
 * Winding number of p (Sunday's crossing rule). A ring that runs clockwise on screen, like the
 * engine's shapes, counts +1 inside. Points within the flattening tolerance of an edge may land on
 * either side.
 */
export function windingNumber(p: Vec2, rs: readonly Ring[]): number {
  const [px, py] = p;
  let wn = 0;
  for (const ring of rs) {
    for (let i = 0; i + 1 < ring.length; i++) {
      const [ax, ay] = ring[i]!, [bx, by] = ring[i + 1]!;
      const side = (bx - ax) * (py - ay) - (px - ax) * (by - ay);
      if (ay <= py) {
        if (by > py && side > 0) wn++;
      } else if (by <= py && side < 0) wn--;
    }
  }
  return wn;
}

export function contains(p: Vec2, rs: readonly Ring[], fillRule: FillRule): boolean {
  const wn = windingNumber(p, rs);
  return fillRule === 'nonzero' ? wn !== 0 : wn % 2 !== 0;
}

/**
 * Exact signed area enclosed by the subpaths: Green's theorem in closed form per cubic, with no
 * flattening. Open subpaths are closed as for fill. Positive means clockwise on screen.
 * Overlapping loops add up, so this is the covered area only for non-overlapping, consistently
 * oriented loops, such as reoriented boolean results.
 */
export function signedArea(subpaths: readonly Subpath[]): number {
  let sum = 0;
  for (const sp of subpaths) {
    for (const [x0, y0, x1, y1, x2, y2, x3, y3] of cubics(sp, true)) {
      sum +=
        (3 *
          ((y3 - y0) * (x1 + x2) -
            (x3 - x0) * (y1 + y2) +
            y1 * (x0 - x2) -
            x1 * (y0 - y2) +
            y3 * (x2 + x0 / 3) -
            x3 * (y2 + y0 / 3))) /
        20;
    }
  }
  return sum;
}
```

```ts
export type RoundedCorners = { readonly subpath: Subpath; readonly clamped: number; readonly skipped: number };

type Fillet = { readonly d: number; readonly k: number };

const ANGLE_EPS = 1e-9;
const LENGTH_EPS = 1e-9;

/**
 * Fillets every corner between two straight segments (Appendix A "Corner fillet").
 * - Tangent distance d = r / tan(φ/2), where φ is the interior angle. It is clamped to half of the
 *   shorter adjacent edge, which shrinks the radius.
 * - Arc handle length is 4/3·tan((π − φ)/4)·r.
 *
 * Counts in the result:
 * - `clamped`: corners whose radius was reduced.
 * - `skipped`: corners left sharp because an adjacent segment is curved, or because the path folds
 *   back on itself.
 *
 * Smooth joins are not corners. An open subpath keeps its end points. When nothing is rounded, the
 * input object is returned as `subpath`.
 */
export function roundCorners(sp: Subpath, radius: number): RoundedCorners {
  const cs = cubics(sp);
  const n = cs.length;
  if (!(radius > 0) || n < 2) return { subpath: sp, clamped: 0, skipped: 0 };
  const edges = cs.map((c) => {
    const dx = c[6] - c[0], dy = c[7] - c[1];
    const len = Math.hypot(dx, dy);
    return { c, len, ux: len > 0 ? dx / len : 0, uy: len > 0 ? dy / len : 0, straight: isStraight(c) };
  });
  // fillets[i] is the corner at the start of edge i.
  const fillets: (Fillet | null)[] = edges.map(() => null);
  let clamped = 0, skipped = 0;
  for (let i = sp.closed ? 0 : 1; i < n; i++) {
    const inc = edges[(i + n - 1) % n]!, out = edges[i]!;
    if (inc.len < LENGTH_EPS || out.len < LENGTH_EPS) continue;
    const [ax, ay] = tangentAt(inc.c, 1), [bx, by] = tangentAt(out.c, 0);
    const turn = Math.abs(Math.atan2(ax * by - ay * bx, ax * bx + ay * by)); // π − φ
    if (turn < ANGLE_EPS) continue;
    if (!inc.straight || !out.straight || Math.PI - turn < ANGLE_EPS) {
      skipped++;
      continue;
    }
    const tanHalf = Math.tan((Math.PI - turn) / 2); // tan(φ/2)
    let d = radius / tanHalf, r = radius;
    const dMax = Math.min(inc.len, out.len) / 2;
    if (d > dMax) {
      d = dMax;
      r = d * tanHalf;
      clamped++;
    }
    fillets[i] = { d, k: (4 / 3) * Math.tan(turn / 4) * r };
  }
  if (fillets.every((f) => f === null)) return { subpath: sp, clamped, skipped };

  // Tangent points of the fillet at the start of edge i: on the incoming edge, then on edge i.
  const before = (i: number, f: Fillet): Vec2 => {
    const e = edges[(i + n - 1) % n]!, v = edges[i]!.c;
    return [v[0] - e.ux * f.d, v[1] - e.uy * f.d];
  };
  const after = (i: number, f: Fillet): Vec2 => {
    const e = edges[i]!;
    return [e.c[0] + e.ux * f.d, e.c[1] + e.uy * f.d];
  };
  const f0 = fillets[0];
  const start: Vec2 = f0 ? after(0, f0) : sp.start;
  const segs: Seg[] = [];
  let at = start;
  for (let i = 0; i < n; i++) {
    const e = edges[i]!;
    const j = (i + 1) % n;
    const next = sp.closed || i + 1 < n ? fillets[j] : null;
    const end: Vec2 = next ? before(j, next) : [e.c[6], e.c[7]];
    if (!e.straight) segs.push([e.c[2], e.c[3], e.c[4], e.c[5], e.c[6], e.c[7]]);
    else if (Math.hypot(end[0] - at[0], end[1] - at[1]) > LENGTH_EPS * Math.max(1, e.len)) segs.push(line(at, end));
    if (next) {
      const t2 = j === 0 ? start : after(j, next);
      const ej = edges[j]!;
      segs.push([end[0] + e.ux * next.k, end[1] + e.uy * next.k, t2[0] - ej.ux * next.k, t2[1] - ej.uy * next.k, t2[0], t2[1]]);
      at = t2;
    } else {
      at = end;
    }
  }
  return { subpath: { start, segs, closed: sp.closed }, clamped, skipped };
}
```

```ts
import paper from 'paper/dist/paper-core.js';
import type { FillRule, Seg, Subpath } from './types.ts';

let shared: paper.PaperScope | undefined;

/**
 * Runs `fn` with the engine's single headless paper.js scope (spec S6, spike finding F5).
 * paper's constructors attach items to whichever scope was activated last, and every PaperScope
 * stays in a static registry forever. So the engine keeps one long-lived scope and activates it on
 * every call. It never inserts items (`settings.insertItems = false`, plus `insert: false` at each
 * call site), so nothing paper creates outlives the call: results leave as plain data.
 */
export function withPaper<T>(fn: (scope: paper.PaperScope) => T): T {
  if (!shared) {
    shared = new paper.PaperScope();
    shared.setup(new shared.Size(1, 1));
    shared.settings.insertItems = false;
  }
  shared.activate();
  return fn(shared);
}

/**
 * Plain subpaths → one paper item: a Path for one subpath, otherwise a CompoundPath. Subpaths with
 * no segments are skipped. The fill rule is set on the item, because paper's booleans read it.
 */
export function toPaper(scope: paper.PaperScope, subpaths: readonly Subpath[], fillRule: FillRule = 'nonzero'): paper.PathItem {
  const paths = subpaths
    .filter((sp) => sp.segs.length > 0)
    .map((sp) => {
      const path = new scope.Path({ insert: false });
      path.add(new scope.Point(sp.start[0], sp.start[1]));
      sp.segs.forEach(([c1x, c1y, c2x, c2y, x, y], i) => {
        const last = path.lastSegment;
        last.handleOut = new scope.Point(c1x - last.point.x, c1y - last.point.y);
        const closesLoop = sp.closed && i === sp.segs.length - 1 && x === sp.start[0] && y === sp.start[1];
        if (!closesLoop) path.add(new scope.Point(x, y));
        const next = closesLoop ? path.firstSegment : path.lastSegment;
        next.handleIn = new scope.Point(c2x - x, c2y - y);
      });
      path.closed = sp.closed;
      return path;
    });
  const item: paper.PathItem =
    paths.length === 1 ? paths[0]! : new scope.CompoundPath({ children: paths, insert: false });
  item.fillRule = fillRule;
  return item;
}

/**
 * paper item → plain subpaths, one per child path with curves. A closed path's last segment ends
 * exactly at its start. Handles are stored relative to their anchor in paper, so non-integer
 * coordinates round-trip within float rounding.
 */
export function fromPaper(item: paper.PathItem): Subpath[] {
  const paths = item.className === 'CompoundPath' ? (item.children as paper.Path[]) : [item as paper.Path];
  return paths
    .filter((p) => p.curves.length > 0)
    .map(
      (p): Subpath => ({
        start: [p.firstSegment.point.x, p.firstSegment.point.y],
        closed: p.closed,
        segs: p.curves.map(
          (c): Seg => [
            c.point1.x + c.handle1.x,
            c.point1.y + c.handle1.y,
            c.point2.x + c.handle2.x,
            c.point2.y + c.handle2.y,
            c.point2.x,
            c.point2.y,
          ],
        ),
      }),
    );
}
```

```ts
/** Centripetal Catmull–Rom through the points: paper `smooth`, α = 0.5, so no cusps or self-loops (D5). */
export function smooth(points: readonly Vec2[], closed: boolean): Subpath {
  const pts = distinct(points, closed);
  if (pts.length < 2) throw new RangeError('smooth needs at least 2 distinct points');
  return withPaper((scope) => {
    const path = new scope.Path({ segments: pts.map(([x, y]) => [x, y]), closed, insert: false });
    path.smooth({ type: 'catmull-rom', factor: 0.5 });
    return fromPaper(path)[0]!;
  });
}

/** Schneider curve fit through the points: paper `simplify`, where `tolerance` is the maximum error (D5). */
export function fit(points: readonly Vec2[], closed: boolean, tolerance = 2.5): Subpath {
  if (!(tolerance > 0)) throw new RangeError(`tolerance must be > 0, got ${tolerance}`);
  const pts = distinct(points, closed);
  if (pts.length < 2) throw new RangeError('fit needs at least 2 distinct points');
  return withPaper((scope) => {
    const path = new scope.Path({ segments: pts.map(([x, y]) => [x, y]), closed, insert: false });
    path.simplify(tolerance);
    return fromPaper(path)[0]!;
  });
}
```

```ts
import { pathBounds } from './bezier.ts';
import { signedArea } from './flatten.ts';
import { fromPaper, toPaper, withPaper } from './paper-adapter.ts';
import type { FillRule, Seg, Subpath } from './types.ts';

export type BooleanOp = 'union' | 'intersect' | 'subtract' | 'exclude';
export type Shape = { readonly subpaths: readonly Subpath[]; readonly fillRule: FillRule };

const PAPER_METHOD = { union: 'unite', intersect: 'intersect', subtract: 'subtract', exclude: 'exclude' } as const;

/**
 * Boolean of two filled shapes through paper.js (D5). Each operand's fill rule is honoured, and an
 * open subpath counts as closed, as SVG fills it.
 *
 * The result is reoriented with `reorient(true, true)` (spike finding F3): outer loops run clockwise
 * and holes counter-clockwise. Nonzero and evenodd then fill it the same way, and `signedArea()` is
 * its covered area.
 *
 * Epsilon handling, relative to the operands' size: zero-length segments and zero-area sliver loops
 * are dropped. When one operand is empty, the other is returned unchanged, without calling paper.
 */
export function booleanOp(op: BooleanOp, a: Shape, b: Shape): Shape {
  const left: Shape = { ...a, subpaths: a.subpaths.filter((sp) => sp.segs.length > 0) };
  const right: Shape = { ...b, subpaths: b.subpaths.filter((sp) => sp.segs.length > 0) };
  if (left.subpaths.length === 0 || right.subpaths.length === 0) return withEmptyOperand(op, left, right);
  const box = pathBounds([...left.subpaths, ...right.subpaths])!;
  const size = Math.max(1, Math.hypot(box.width, box.height));
  return withPaper((scope) => {
    const pa = toPaper(scope, left.subpaths, left.fillRule);
    const pb = toPaper(scope, right.subpaths, right.fillRule);
    const result = pa[PAPER_METHOD[op]](pb, { insert: false });
    result.reorient(true, true);
    return { subpaths: tidy(fromPaper(result), size), fillRule: 'nonzero' };
  });
}

function withEmptyOperand(op: BooleanOp, a: Shape, b: Shape): Shape {
  const none: Shape = { subpaths: [], fillRule: 'nonzero' };
  if (op === 'intersect') return none;
  if (op === 'subtract') return a.subpaths.length > 0 ? a : none;
  return a.subpaths.length > 0 ? a : b; // union and exclude keep whichever side is not empty
}

/**
 * Drops segments that do not move (all three points within 1e-9·size of the current point) and
 * loops whose area is below (1e-4·size)². A closed loop keeps ending exactly at its start.
 */
function tidy(subpaths: readonly Subpath[], size: number): Subpath[] {
  const pointEps = 1e-9 * size, areaEps = (1e-4 * size) ** 2;
  const out: Subpath[] = [];
  for (const sp of subpaths) {
    let [px, py] = sp.start;
    const segs: Seg[] = [];
    for (const s of sp.segs) {
      const moves = Math.max(Math.hypot(s[0] - px, s[1] - py), Math.hypot(s[2] - px, s[3] - py), Math.hypot(s[4] - px, s[5] - py)) > pointEps;
      if (!moves) continue;
      segs.push(s);
      px = s[4];
      py = s[5];
    }
    const last = segs.at(-1);
    if (sp.closed && last && Math.hypot(last[4] - sp.start[0], last[5] - sp.start[1]) <= pointEps) {
      segs[segs.length - 1] = [last[0], last[1], last[2], last[3], sp.start[0], sp.start[1]];
    }
    const clean: Subpath = { start: sp.start, segs, closed: sp.closed };
    if (segs.length > 0 && Math.abs(signedArea([clean])) >= areaEps) out.push(clean);
  }
  return out;
}
```
