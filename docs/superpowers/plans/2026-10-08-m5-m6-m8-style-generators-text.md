## Decisions (record in spec A3 at the end)
1. **defs by name.** `Doc.defs: Record<name, LinearGradientDef | RadialGradientDef | FilterDef>`. A paint resolves token → gradient def (`url(#__def_<name>)`) → CSS color. Def names never equal a token name or parse as a CSS color. Only defs a style references are emitted (sorted by name), so unused defs cost nothing and no delete op is needed. Old documents load with `defs: {}`.
2. **Gradients** use objectBoundingBox units: linear by `angle` (0° = left→right, 90° = top→bottom), radial by `center`/`radius`/`focal` fractions. User stops (2–9) are kept exactly; midpoints are inserted into the widest gap, interpolated in OKLab, until 5–9 stops (target `min(9, max(5, 2k−1))`). Stop colors may be tokens (live).
3. **Filters** (`blur`, `shadow`) are defs referenced by `style.filter`; `style.blend` emits `mix-blend-mode`. Bounds never include strokes or effects.
4. **mask** is an opacity fade stored on the node (`mask: {type, angle, from, to}`), not a node reference (same reasoning as M4 clip).
5. **Text node** stores its measured ink box (`ink`, local space). Deviation from A3.4 ("derived data not stored"): measuring needs font files, which the document does not hold. Ops get fonts through `BatchOptions.fonts`; the server passes its bundled fonts. World bounds of text = box around the transformed ink box.
6. **text_on_path** copies the guide path's first subpath into the text node (`at.kind = 'path'`), like clip; the guide is removed unless `keep`.
7. **Generators** derive randomness per node: `rngFor(seed ?? doc.seed, nodeId, salt)` (Alea) + simplex noise (`simplex-noise@4.0.3`). Copy generators (scatter, repeat_along_path, array) output a new group of clones; the source is removed unless `keep: true`. `Limits.maxGenerated` (default 2000, env `AGENT_ILLUSTRATOR_MAX_GENERATED`) caps copies/samples per op; node budget is checked before cloning.
8. **Bundled fonts** stay Tajawal Regular/Bold (Latin + Arabic). No opentype.js (S2).

- `contrastRatio(a: string, b: string): number | undefined`: WCAG 2.x ratio (culori `wcagContrast`) of two CSS colors, alpha ignored; undefined when either is not a color. Tests: black/white = 21; `#777777` vs white ≈ 4.48; `#767676` vs white ≈ 4.54 (toBeCloseTo 2); same color = 1; symmetric.

- `makePalette(base: string, harmony: Harmony, steps: number, prefix: string): Record<string, string> | undefined` (undefined when base is not a color). Roles and hue offsets: monochrome `{primary: 0}`; complementary `{primary: 0, accent: 180}`; analogous `{primary: 0, secondary: 30, tertiary: -30}`; triadic `{primary: 0, secondary: 120, tertiary: 240}`. Last: `${prefix}.neutral.${k}` with chroma `min(C0, 0.02)`, hue h0. Every color gamut-mapped to sRGB in OKLCH (`toGamut('rgb', 'oklch')`), output `formatHex` (lowercase `#rrggbb`). Hue mod 360.
- Tests: all values `#rrggbb`; each ramp's OKLCH L strictly decreases; complementary accent hue ≈ primary + 180 (±3°) for `#2a9d8f`; analogous/triadic role counts; an in-gamut base gives `${prefix}.primary` equal to the base hex (±1 per channel); steps 3 and 9; gray base works; deterministic.
