## Decisions
1. **MCP surface = 10 tools:** `create_document`, `apply_ops`, `render`, `export_svg` (M3) + `describe_scene`, `measure`, `lint`, `history`, `document_io`, `guide`; one prompt `illustrate`.
2. **Analysis lives in the engine** (`engine/src/analysis/`, may import `scene`, `geometry`, `render`; never `ops`). Tools are thin wrappers.
3. **Lint** default checks: `off_canvas`, `degenerate`, `tiny`, `near_miss`, `text_overlap`, `contrast`. `overlap` is opt-in (illustrations overlap on purpose). Every issue has `{ code, severity, ids, message, hint, fix? }`, where `fix` is a ready op call. `apply_ops` returns cheap checks for the ids it touched (FR-10.4).
4. **Contrast** is sampled from a render of the scene without the text node, over the text's box: ratio = min over the 5th and 95th luminance-percentile pixel colors; WCAG thresholds 4.5, or 3 for large text (size ≥ 24, or ≥ 18.66 and weight ≥ 700).
5. **History:** named checkpoints + an automatic undo stack (50) in `DocumentStore`; restore and undo are themselves undoable; `$last` resets after either.
6. **document_io** reads and writes only `<AGENT_ILLUSTRATOR_DOCS_DIR>/<name>.json`, with a strict name pattern and a 20 MB load cap. Load creates a new session.
7. **Agent kit:** content is Markdown/YAML in `packages/agent-kit/content/`. `guide(topic)` serves files, a generated op catalog (`ops`) and per-op detail (`op:<name>`). A CI test checks that every op named in the content exists and that every ```json op batch in it runs.
8. **Eval** (`eval/`, private package): CI render regression (fixtures → PNG → pixelmatch vs committed baselines); dev-only harness against one OpenAI-compatible endpoint; raw-SVG baseline; static HTML report + rubric. Model runs need API keys, so the owner runs them; a scripted fake model tests the harness offline.

## T1 (M7): describe_scene + measure — engine
**Files:** `packages/engine/src/analysis/describe.ts`, `packages/engine/src/analysis/measure.ts`, `packages/engine/test/analysis/describe.test.ts`, `packages/engine/test/analysis/measure.test.ts` (all new).
- `describeScene(doc: Doc, options: { detail?: 'outline' | 'normal' | 'full'; root?: string; maxNodes?: number } = {}): SceneDescription` (default `normal`, maxNodes 300).
  - `SceneDescription = { canvas, seed, tokens: string[] (names), defs: { name, kind }[], nodeCount, shown, truncated, nodes: NodeInfo[] }`; `root` describes that subtree only (unknown id → `requireNode` error).
  - `NodeInfo` (depth-first, back → front, children nested): all levels `id, type, bounds` (rounded to 0.01, null when empty); groups `children` (or `childCount` once maxNodes is hit).
  - `normal` adds: `fill`/`stroke` as stored plus the resolved color when they are a token or gradient (`"palette.primary → #2a9d8f"`, `"sky_fade (gradient)"`), `strokeWidth`, `opacity`, `filter`, `blend`, `mask: true`, `clip: true`, `source` (= `meta.source.kind` when present), paths `segments` (count), text `text` (first 80 chars), `font` (`"Tajawal 24/700"`), `anchor`.
  - `full` adds: `transform` (when not identity), path `subpaths` with numbers rounded to 0.01, text `at` and full `font`, `meta.source`.
  - When the count passes maxNodes: stop descending, set `truncated: true`; `shown` = nodes listed.
- `measure(doc: Doc, ids: readonly string[]): Measurement` (1–50 ids; unknown id → `requireNode` error; duplicates removed).
  - `nodes[id] = { bounds, center: [x, y] | null, area: number | null, length: number | null }`. Path area = |`signedArea`(world subpaths)| (`geometry/flatten.ts`), length = Σ `measure(sp).length` (`geometry/bezier.ts`); groups sum their descendant paths; text → null for both. Round to 0.01.
  - `pairs` (2–12 ids, every pair in input order): `{ a, b, centerDistance, gap: { x, y }, overlap, overlapArea, exact }`. Gap per axis = distance between the boxes on that axis (0 when they overlap on it). Two paths: `booleanOp('intersect', …)` (`geometry/boolean.ts`) → area > 1e-6 means overlap, `exact: true`. Otherwise (groups, text) box intersection area, `exact: false`.
- Tests: exact bounds/area of a rect and a circle (πr² within 0.5%), path length of a line and a circle, group sums, text gives nulls, pair gaps for separated and overlapping shapes, exact boolean overlap vs box-only, describe detail levels, token/gradient display, root subtree, truncation, determinism.

## T2 (M7): lint — engine
**Files:** `packages/engine/src/analysis/lint.ts`, `packages/engine/test/analysis/lint.test.ts` (new).
- `export const LINT_CHECKS = ['off_canvas', 'degenerate', 'tiny', 'near_miss', 'text_overlap', 'overlap', 'contrast'] as const; export type LintCheck`; `DEFAULT_CHECKS` = all but `overlap`; `INCREMENTAL_CHECKS` = `off_canvas, degenerate, tiny, near_miss, text_overlap`.
- `LintIssue = { code: string; severity: 'warning' | 'info'; ids: string[]; message: string; hint: string; fix?: { op: string; [k: string]: unknown } }`.
- `lint(doc, options: { checks?; ids?: readonly string[]; fonts?: RasterFonts; tolerance?: number (2); tinySize?: number (2); maxIssues?: number (50) } = {}): { issues: LintIssue[]; truncated: boolean; checked: LintCheck[] }`. `ids` restricts per-node checks to those nodes, and pair checks to pairs with at least one of them (incremental mode). Leaves = path and text nodes.
  - `off_canvas` (warning): a leaf whose world bounds miss the canvas entirely; fix `{op:'place', ids:[id], relative_to:'canvas', anchor:'center'}`. `partly_off_canvas` (info): crosses an edge, unless its box spans ≥ 90% of the canvas width or height (backgrounds, bleeds).
  - `degenerate` (warning): a path with no segments or a zero-size box (both sides < 1e-6); `empty_group` (info); `no_ink` (warning) for text with `ink: null`. Fix `{op:'delete', ids:[id]}`.
  - `tiny` (info): a leaf whose larger side is in (0, tinySize).
  - `near_miss` (warning): two siblings (same parent) whose left, right, top, bottom, center-x or center-y values differ by more than 0.01 and at most `tolerance`; report the closest edge per pair; fix `{op:'align', ids:[a, b], edge}` (edges as in `ops/layout.ts`: left, right, top, bottom, center-x, center-y). Cap 300 siblings per parent.
  - `text_overlap` (warning): two text nodes whose boxes intersect with positive area.
  - `overlap` (info, opt-in): leaf paths that are not ancestors of each other, rbush candidates (`analysis/spatial-index.ts` style), confirmed with `booleanOp('intersect')` area > 1% of the smaller path's area; at most 200 candidate pairs.
  - `contrast`: for each text node with a solid fill (default black; skip gradients), at most 50: render the doc without that node (copy with the node removed from `nodes` and from its parent's list) via `rasterize(copy, { region: text box grown by 1 px and clamped to the canvas, fonts, background: resolved canvas background or white })`; take the 5th and 95th percentile pixels by WCAG luminance; ratio = min of `contrastRatio(text, p5)`, `contrastRatio(text, p95)` (`scene/color.ts`). Below threshold (decision 4) → `low_contrast` warning with the ratio, and fix `{op:'style', ids:[id], style:{fill: suggestion}}`: the text color with OKLCH lightness moved in 0.05 steps away from the background until it passes (fallback black or white). Skip text fully off canvas.
- Sort issues: warnings first, then code, then ids. Cut at `maxIssues` → `truncated: true`.
- Tests (seeded defects, M7 acceptance): one fixture scene per check that must report it, a clean scene with zero warnings, `ids` restriction, determinism, overlap opt-in, gray text on a gray rect → `low_contrast` and its fix passes when applied, black on white passes.
